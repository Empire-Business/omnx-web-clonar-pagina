# Clonar página

Salva uma cópia local de uma página pública como referência de estudo. Referência não é plágio: a cópia não é publicada, e nada se passa por marca real. Só copia o que qualquer pessoa vê sem entrar em conta.

Guia visual: abra o `COMO-FUNCIONA.html` desta pasta (dois cliques; funciona sem internet).

## Como instalar

**Direto do GitHub:** no Claude Code, diga: "Instale a skill a partir de https://github.com/Empire-Business/omnx-web-clonar-pagina". Para atualizar, diga: "Atualize a skill a partir de https://github.com/Empire-Business/omnx-web-clonar-pagina". A IA baixa e copia os arquivos.

Se você já baixou esta pasta:

O caminho mais fácil é pedir para a sua IA:

1. Abra o Claude Code numa conversa nova.
2. Diga: "Instale a skill omnx-web-clonar-pagina a partir desta pasta" e indique onde a pasta está.
3. A IA copia os arquivos. Você vai ver uma mensagem dizendo que a skill foi instalada.
4. Feche e abra a conversa de novo, para a skill aparecer.

### Mac ou Linux, se preferir fazer sem a IA

Peça para a IA executar o arquivo `install.sh`. Ele copia a pasta para `~/.claude/skills/omnx-web-clonar-pagina` (`~` é a sua pasta pessoal).

### Windows

1. Peça para a IA: "Copie esta pasta para `%USERPROFILE%\.claude\skills\omnx-web-clonar-pagina`".
2. Sem IA: copie a pasta com esse nome para `%USERPROFILE%\.claude\skills\` pelo Explorador de Arquivos.
3. Feche e abra a conversa.

## Como usar

- "Guarda esta página como referência: (endereço)"
- "Clona esta página para eu estudar o layout."
- "Salva este site no meu computador para consulta."
- "Baixa esta landing page e me diz o que faltou."

## O que você precisa ter

- Claude Code instalado
- Python 3
- Google Chrome, Edge ou Chromium
- Internet

## O que esta skill não faz

- Referência não é plágio: textos e imagens continuam dos donos
- Não publica a cópia nem se passa por marca real
- Não entra em conta, não pede senha, não passa por captcha
- Criar uma página própria inspirada: Morfo
- Escrever o texto da página: Rita
- Extrair dados de sites: Tales
- Vídeos e iframes continuam vindo do site original
- Sites podem recusar o acesso automático
- Scripts ficam de fora, então pode haver diferença visual
